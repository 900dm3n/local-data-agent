# 离线演示与观察要点

## 快速演示

安装依赖后运行 `python -m langchain_data_agent serve`，打开本地工作台。创建离线演示数据，选择离线完整分析。CLI 对应命令见 README。

基准是合成支付、退款、渠道和工单数据。示例八月支付 400 元、退款 20 元、净额 380 元；九月支付 400 元、退款 90 元、净额 310 元。现金净额按事件发生月计算，跨月退款不回溯到支付月。该示例用于复核链路，不是企业真实经营数据。

## 应观察的产物

1. 源注册、冻结快照与已批准指标。
2. 工具请求、执行结果、命名计划步骤及依赖。
3. SQL 与完整 Parquet 结果，而非仅预览。
4. 源事件核对、引用与报告发布时间。
5. 追问后的旧报告保留与结果复用。

## 回放与真实模型的区别

离线回放使用固定动作通过真实框架与执行器，验证软件链路。真实模式的工具与计划由模型生成，可能规划错误、请求超时或达到预算。公开版本不包含私人真实模型日志，也不宣称离线演示证明通用智能。

## 更大数据

`scripts/verify_offline_business.py` 使用合成大数据，覆盖连续追问、零基期、渠道缺失及错误计划修复。源审计和参考金额在模型工具可见范围之外。`scripts/verify_langchain.py --live` 是可选的真实模型小样本验证，会发生网络调用及费用。
